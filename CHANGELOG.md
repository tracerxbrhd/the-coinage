# Changelog

## 1.0.1

- Fixed Coin Purse equipability in Curios slots, including setups using Accessories Compatibility Layer.
- Added native Accessories support for the Belt and Charm slots.

## 1.0.0

- Initial public release.
- Added Copper, Silver and Gold Coins and the Coin Purse.
- Added automatic pickup, rewards, atomic payments and merchant integration.
- Added configurable exchange offers, profession trades, world loot, archaeology and optional mob drops.
- Added U-API service integration, public API, English/Russian localization and accessory compatibility.
